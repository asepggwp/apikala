ApiKala

Satu catatan titik api yang konsisten sejak 2000: MODIS + VIIRS diharmonisasi

Petugas karhutla perlu tahu: apakah titik api di wilayahnya bulan ini tidak biasa, dan kapan musim rawannya? Catatan satelit 20+ tahun terpecah di dua sensor yang angkanya tidak sebanding — VIIRS (375 m) mencatat jauh lebih banyak titik daripada MODIS (1 km) untuk kebakaran yang sama. Aplikasi ini menyamakan keduanya ke satu satuan (setara MODIS), lalu menyajikannya sebagai kalender.
